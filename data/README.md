# Data

This directory is intentionally ignored by git.

Expected local layout after downloading FloorPlanCAD:

```text
data/raw/FloorPlanCAD/
  train/
  val/
  test/
```

The official dataset provides SVG drawings with annotation fields, PNG renderings, and COCO visualization folders. Keep all raw data local and do not commit it.

If the official download link requires a browser login or Google Drive confirmation, download manually and place the extracted files here.
