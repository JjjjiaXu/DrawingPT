## 01 · DrawingPT v0 数据资产与训练闭环

**状态：正式 controlled run 已完成，预训练小幅优于 scratch。**

**本期结论：** DrawingPT v0 已从设计草案推进到服务器 GPU 可运行闭环；本期完成 1% seed0304、1000-step、class-aware + inverse-sqrt 的 scratch/pretrained 正式对照，pretrained 在 macro F1 与 rare macro F1 上小幅领先。

- 生成并冻结 FloorPlanCAD primitive token manifest：11,602 张 SVG，共 12,621,288 个 primitive token；按 2048 token/window 得到 14,117 个 window。
- 固定 1%、5%、10%、25%、50%、100% train 低标注清单，seed 为 304、1004、2026；同一 seed 下小比例是大比例前缀，便于后续 label-efficiency curve 对比。
- 补齐 Dataset、masked primitive pretrain、semantic primitive classification 三个最小训练入口；服务器 processed SVG 布局也已兼容。
- 服务器完成 2048-token masked pretrain short：100 step，loss 1.642630 降到 0.107217，生成 checkpoint SHA-256 ceb52ad65ae94c69a9b0409fb2404b875f33a2de6975d5190862efb09d50317e。
- semantic scratch 诊断证明 class 0=background/unlabeled 参与 loss 会导致 all accuracy 虚高但 foreground F1 为 0；之后改成 foreground-only loss。
- foreground-only scratch/pretrained/weighted smoke 都已跑通；weighted scratch 将 foreground macro F1 从 0.0168 小幅提高到 0.0209，下一步处理 wall/window/sink 高频类主导的问题。
- 新增 `--sampler class_aware` 训练入口：按 foreground 类别稀有度给 window 加权，默认 random 保持旧实验兼容；三个服务器 sbatch 脚本已支持通过 SAMPLER 环境变量透传。
- 完成 1% seed0304 class-aware sampler exposure audit：一轮仍采 88 个 window，但 replacement 后 unique window 为 46；rare token share 从 8.48% 到 8.82%，wall share 从 28.04% 小降到 27.70%。
- 本机 CPU 20-step class-aware+weighted sanity 可正常输出 validation summary，但 macro F1 只有 0.0024；它只证明入口可运行，不能作为效果提升证据。
- 新增正式 controlled run 方案和 Slurm 提交入口：scratch 与 pretrained 两组串行 afterok，默认单 GPU、1000 steps、2048-token window、full val、class-aware sampler、inverse-sqrt class weighting。
- 服务器完成两组 1000-step controlled run：scratch job 1440 与 pretrained job 1441 均 COMPLETED/ExitCode 0:0；pretrained 在 full val 上 foreground accuracy 0.2178、macro F1 0.0320、rare macro F1 0.0083，高于 scratch 的 0.2048、0.0270、0.0022。

## 02 · FloorPlanCAD 数据画像与长尾风险

**状态：分布统计已补齐，转化为采样与评估门禁。**

**本期结论：** FloorPlanCAD 的核心风险不是数据量小，而是图元形态和语义类别都高度长尾：这直接解释了为什么 1% smoke 会被 wall/window/sink 主导。

- 补齐全量 11,602 张 SVG 的 raw primitive、semantic element、instance 和 split 级统计，用于回答“数据到底长什么样”。
- raw SVG primitive 共 12,621,288 个，其中 path 12,454,181 个，占 98.68%；circle 157,009 个，占 1.24%；ellipse 10,098 个，占 0.08%。
- 单图 primitive 数中位数为 544、均值为 1,087.85、p95 为 3,541、最大值为 53,919；另有 79 张图超过 10,000 个 primitive，说明按整图训练会被长尾大图拖住。
- 带 semanticId 的元素共 5,828,994 个，35 类全量均出现；最大类 wall 有 1,362,387 个，占 23.37%，而 rolling door 只有 98 个，占 0.0017%。
- val split 只覆盖 33/35 类，缺少 revolving door 和 rolling door；因此 rare-class 指标不能只看单个小验证集，需要记录 per-class support 和多 seed。

| 指标 | 本期值 |
| --- | --- |
| raw SVG primitives | 12,621,288 |
| path share | 98.68% |
| semanticId elements | 5,828,994 |
| wall semantic share | 23.37% |
| rolling door elements | 98 |
| drawings with 10k+ primitives | 79 |

**数据画像如何影响实验设计：** 这些统计把“为什么要窗口化、为什么要 class-aware、为什么不能只看 overall F1”变成可解释的实验约束。

| 观察 | 关键数字 | 对实验的含义 |
| --- | --- | --- |
| 图元形态单一 | path 占 98.68% | v0 先把 path 几何编码做稳，比过早追求复杂 DWG 结构更实际 |
| 单图规模长尾 | 中位数 544，最大值 53,919 | 需要 2048-token window 和大图切窗策略，不能假设每张图复杂度接近 |
| 语义类别长尾 | wall 23.37%，rolling door 0.0017% | low-label 实验必须报告 macro/rare F1，且采样要主动覆盖稀有类 |
| 验证集稀有类缺失 | val 覆盖 33/35 类 | rare-class 结论要结合 per-class support 和多 seed，避免把验证集缺类误读为模型能力 |

**数据画像带来的方法收束：**

- 把 DrawingPT v0 的第一阶段重点明确为 primitive-level 表示学习，而不是直接追完整 CAD/DWG 语义层级。
- 把 class-aware sampling 从“可选优化”提升为下一轮实验门禁，因为当前类别分布会天然奖励高频类预测。
- 把 evaluation 从单一 foreground accuracy 改成 foreground macro F1、rare-class F1、per-class support 三件套。

*表述边界：这是数据与评估设计证据，不是模型效果证据；它解释实验风险和下一步设计合理性。*

**可信边界：** 统计基于公开 11,602 张 SVG baseline split；FloorPlanCAD 官网后续提到的 15,663 张版本不在本轮 baseline 内。SVG primitive 统计不恢复 DWG block/layer/topology，length proxy 也不是米或平方米。

**下一门禁：** 在下轮 semantic smoke 中加入 class-aware window sampler 的覆盖审计：每个低标注比例输出训练窗口数、覆盖类别数、rare-class support，并与当前 1% seed0304 smoke 对齐比较。

## 03 · CAD/平面图文献调研与方法定位

**状态：文献脉络已整理，转化为实验设计约束。**

**本期结论：** 本期文献调研把 DrawingPT 的创新点收窄到“矢量原生自监督预训练 + 低标注验证”，并明确 VLM、文本增强和监督 spotting baseline 的对照边界。

- 整理 7 篇 10-line 文献笔记：FloorPlanCAD、CADSpotting、Brep2Shape、GeoPT、ArchPlanVQA、HouseMind、TextEnhancedCAD。
- 确定 FloorPlanCAD 是主 benchmark；任务是 panoptic symbol spotting，SVG 可读 semanticId、instanceId、path/circle/ellipse 等 primitive，但类别长尾、DWG 原生结构会部分丢失。
- 确定 CADSpotting、CADTransformer、SymPoint、GAT-CADNet 属于监督 baseline 或复现参考；DrawingPT 要避免只做另一个强监督检测器。
- 从 Brep2Shape 和 GeoPT 提取预训练叙事：几何 token、自监督目标、label-efficiency curve、预训练数据量/模型规模消融。
- 从 ArchPlanVQA、HouseMind、TextEnhancedCAD 提取边界：VLM 对照要冻结 prompt/渲染/评分；文本增强 CAD spotting 已构成 novelty 风险，DrawingPT 不能声称首次使用 CAD 文本。

**下一门禁：** 把文献结论落实为两个实验门禁：class-aware sampling 的低标注曲线，以及一个小型 VLM prompt baseline。

## 04 · 工程造价方向与 pseudo-BoQ 中间层

**状态：调研完成，工程量 proxy 已冻结。**

**本期结论：** 造价方向被收束为“图纸理解 → 工程量 proxy → BoQ/造价”的可解释链路，而不是直接黑箱预测总价。

- 完成工程造价自动估算调研：成熟路线主要是 BIM/结构化工程量到造价，或历史项目特征到造价预测；2D CAD 原始图元直接到完整造价的成熟学术路线还少。
- 明确 DrawingPT 的短期定位：作为图纸理解和表示学习前端，先抽取构件、符号、尺寸/数量关系，再服务 quantity takeoff、BoQ/BoM 和造价模型。
